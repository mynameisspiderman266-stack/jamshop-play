# 果酱连锁店 · 网页版

戳爆水果引发同色连锁，装满订单罐做果酱。

网页版本：1.0.0；关卡数据版本：v9；30关剧情＋第31关无限模式，共7章。

## 在线游玩

仓库所有者启用GitHub Pages后，在仓库 Settings → Pages → Visit site 获取游玩地址。

电脑使用鼠标，手机使用触屏；建议竖屏。声音需要点击页面后播放。进度保存在当前浏览器中，不跨设备同步。

## 部署

将本目录的全部内容放在仓库根目录，确保 index.html 与 Build/ 同级。
在 Settings → Pages 选择 Deploy from a branch、main、/(root)，保存后等待部署完成。
请上传解压后的文件，不要只上传ZIP。不要双击本地 index.html 作为运行验证。

这是已编译的静态网页发行包，包含运行资源；不包含Unity工程源码或开发工具。未授予开源许可。
